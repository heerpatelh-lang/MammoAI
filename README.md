# MammoAI 🩺

An AI-powered mammography analysis tool that uses machine learning to assist in breast cancer detection.

## Features
- AI/ML-based mammogram image analysis
- Visual explanations of model predictions
- Clean, modern user interface

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- TensorFlow.js for in-browser AI inference

## Live Demo
Deployed via Vercel — see the live site link above.

## Usage
Upload a mammogram image and the AI model will analyze it, providing a prediction along with a visual explanation of the key areas it focused on.
